# M&M — Makar & Matvey

Онлайн-домашка по английскому для Макара и Матвея: подготовка к британской международной школе.

- `index.html` — список уроков
- `lessons/<номер темы>/` — интерактивный урок (слова, история, игры, карточки)

Номера тем — по плану «Макар и Матвей — план обучения и инструкции к урокам» (Google Диск, папка «Матвей»).

# Lesson builder

Собирает для каждого урока две страницы: `lessons/<id>/index.html` (интерактивный урок: слова, история, 7 игр, карточки) и `lessons/<id>/homework.html` (домашка: 6 заданий, слова пишут сами).

1. Отрисовать страницы урока в PNG (`pdftoppm -r 165 -png`) и вырезать картинки: `crop.py` (координаты карточек и кадров истории задаются для каждого урока).
2. Сложить картинки в `img/<dir>/`: `<слово>.jpg` (пробелы → `_`), `hero.jpg`, `s1.jpg…sN.jpg`.
3. Описать урок в `data.py` (слова, рассказ, задания игр, загадки, задание 4 домашки, текст для чтения, творческое задание).
4. `python3 build.py 1.5` — собрать один урок (без аргументов — все), затем добавить урок в `index.html`.

Стили берутся из урока 1.3. Немецкие подсказки в материалах не используем.
